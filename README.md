# اپلیکیشن جستجوی فتوا و مسئله شرعی

یک اپلیکیشن جامع فارسی برای جستجوی احکام شرعی و فتوای مراجع عظام تقلید.

## ویژگی‌ها

- 🔍 **جستجوی پیشرفته**: استفاده از الگوریتم Fuse.js برای جستجوی هوشمند در متن فتواها، توضیحات ساده و کلیدواژه‌ها
- 👥 **دو مرجع تقلید**: امام خامنه‌ای و آیت‌الله سیستانی
- 📚 **دسته‌بندی موضوعی**: نماز، روزه، خمس، ارث، معاملات و...
- 💡 **بیان ساده**: توضیح مسائل پیچیده فقهی به زبان ساده و قابل فهم
- 🎨 **رابط کاربری زیبا**: طراحی مدرن و واکنش‌گرا با پشتیبانی کامل از زبان فارسی
- 📱 **واکنش‌گرا**: قابل استفاده در موبایل، تبلت و دسکتاپ

## ساختار داده‌ها

داده‌های فتواها در فایل `data/fatwas.json` ذخیره شده‌اند. هر رکورد شامل:

```json
{
  "id": 1,
  "title": "عنوان مسئله",
  "marja": "نام مرجع",
  "category": "دسته‌بندی",
  "fatwa": "متن فتوا",
  "simpleExplanation": "توضیح ساده",
  "keywords": ["کلیدواژه1", "کلیدواژه2"]
}
```

## نصب و اجرا

```bash
# نصب وابستگی‌ها
npm install

# اجرای برنامه در حالت توسعه
npm run dev

# ساخت نسخه تولید
npm run build

# پیش‌نمایش نسخه تولید
npm run preview
```

## افزودن فتوای جدید

برای افزودن فتوای جدید، فایل `data/fatwas.json` را ویرایش کنید و یک رکورد جدید اضافه نمایید.

## تکنولوژی‌های استفاده شده

- React 18
- Vite
